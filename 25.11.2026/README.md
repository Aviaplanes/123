# Найди пару — ПК, 25.11.2026

Небольшая игра для **Windows 10/11 x64** на C# / Windows Forms.
Вся логика и интерфейс — в одном `Program.cs`, без картинок и сторонних библиотек.

- 16 карточек, 8 пар эмодзи; новая случайная раскладка при каждом старте.
- Открой две карточки: одинаковые остаются открытыми, разные закрываются через 750 мс.
- Пока показывается несовпавшая пара, другие карточки не открываются.
- Счётчик ходов, сообщение о победе и кнопка «Новая игра».
- Работает офлайн, ничего не скачивает.

## Сборка через GitHub Actions

Workflow будет добавлен вручную и в текущие изменения не входит.
Для него нужны runner `windows-latest`, .NET SDK `10.0.x` и команда
`dotnet publish` из раздела ниже. Результат `artifacts/MemoryGame.exe`
можно загрузить через `actions/upload-artifact@v4`.

После успешной сборки скачай артефакт из вкладки **Actions**, распакуй ZIP
и запусти `MemoryGame.exe`.

Устанавливать .NET на игровой компьютер **не нужно**: среда включена в EXE.
Поэтому EXE занимает заметно больше места, чем исходный код.
При первом запуске .NET распакует нативные библиотеки во временную папку.
Файл не подписан коммерческим сертификатом: Windows может показать предупреждение SmartScreen.
Срок хранения артефакта задаётся в workflow; EXE можно скачать и сохранить.

## Собрать самостоятельно

Нужны Windows и **.NET SDK 10**:

```powershell
dotnet run --project 25.11.2026/MemoryGame.csproj
```

Один самостоятельный EXE (эту же команду можно использовать в Actions):

```powershell
dotnet publish 25.11.2026/MemoryGame.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -p:DebugSymbols=false -o artifacts
```

Результат: `artifacts/MemoryGame.exe`.

## Быстрая ручная проверка

- Нажми одну карточку дважды — ход не засчитывается.
- Открой разные карточки и быстро нажми третью — она не открывается до закрытия пары.
- Нажми «Новая игра», пока пара ждёт закрытия — новая партия остаётся корректной.
- Собери 8 пар — появляется сообщение о победе; найденные пары нельзя открыть повторно.
- Измени размер окна — поле остаётся 4×4.

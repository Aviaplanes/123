# Найди пару 🎯 (Memory Game)

Игра на C# / Windows Forms: поле 4×4 (16 клеток = 8 пар эмодзи).
Кликни по клетке, открой две — если эмодзи совпали, пара остаётся,
иначе клетки закроются. Найди все 8 пар, чтобы выиграть.

## Запуск (только Windows)
1. Установи .NET 8 SDK (https://dotnet.microsoft.com/download).
2. В папке проекта выполни:
   ```
   dotnet run
   ```

## Файлы
- `Program.cs` — точка входа (запуск формы).
- `Form1.cs` — вся логика игры и раскладка клеток.
- `MemoryGame.csproj` — настройки проекта (WinForms, net8.0-windows).
